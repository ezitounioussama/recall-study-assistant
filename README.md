# Recall

An AI study assistant that turns your own notes into a spaced-repetition
practice loop. Upload material, ask questions and get answers cited back to the
source, generate quizzes, and review cards on an FSRS schedule.

Work in progress. See [`docs/roadmap.md`](docs/roadmap.md) for what is built and
what is next.
